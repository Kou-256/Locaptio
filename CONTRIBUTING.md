# Contributing / 開発への参加

Issues and pull requests are welcome in Japanese or English.
日本語・英語どちらのIssue／Pull Requestも歓迎します。

- Start with [README.md](README.md) / [README.en.md](README.en.md).
- Use .NET 10 SDK on Windows and .NET 8 Runtime for tests.
- See [architecture](docs/architecture.md) and [testing](docs/testing.md).
- Keep model weights, recordings, credentials, local settings and generated files out of commits.
- Describe the concrete problem, before/after behavior and relevant validation.
- Audio, GPU, NPU and Windows integration changes need appropriate device testing; pure CI checks do not prove hardware support.
- Do not post personal recordings or transcripts. Use synthetic/non-sensitive examples.

By submitting code, you agree that your contribution is licensed under the project's MIT license. Third-party assets retain their original licenses.
