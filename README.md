<h1 align="center">Locaptio</h1>
<p align="center">Local captions, translation & audio recording for Windows 11</p>
<p align="center"><b>日本語</b> · <a href="README.en.md">English</a> · <a href="https://locaptio.vercel.app">公式サイト</a> · <a href="https://github.com/Kou-256/Locaptio/releases/latest/download/Locaptio-Setup-x64.exe">Download</a> · <a href="https://github.com/Kou-256/Locaptio/issues">Issues</a></p>

Windows 11向けの、ローカル音声認識・英日翻訳・字幕オーバーレイ・録音アプリです。動画や会議の音声を読みながら、必要な文章と音声を保存できます。

> **開発中の個人プロジェクトです。** 現在の画面表示は主に日本語です。英語の利用説明は [English README](README.en.md) を参照してください。精度と速度は音声・モデル・ハードウェアによって変わります。

## できること

- **英語→日本語の翻訳／日本語の文字起こし**を切り替え。
- PC内音声、マイク、指定アプリ、**PC内音声＋マイクの同時入力**。
- 英文を先に表示し、FuguMTの速報訳と任意のQwen3による文脈訳で更新。
- **文字だけが浮かぶ字幕**。言語の配置・色・サイズ・行間を変更可能。
- 本体と字幕の**背景・文字の透明度を個別設定**。初期値は本体背景透過率10%、字幕背景透過率20%、文字は不透明度100%（英語: 水色／日本語: 白）。
- 全履歴を表示し、上へスクロールした位置を保持。
- UTF-8テキスト保存、**WAV／MP3／M4A録音**。保存先を別々に指定。
- CPU、NVIDIA CUDA、DirectML翻訳、実験的なAMD XDNA 2 NPU認識。
- Windowsライブキャプションが認識した文章の取り込み。

## ダウンロード・必要環境

### v1.0.41 の録音・再生の使い分け

- **Start**：録音せずに文字起こしを開始・再開します。入力音声を切り替えても、それまでの会話は残ります。
- **新規録音**：名前と保存先を指定すると専用フォルダーを作成し、録音と新しい文字起こしを開始します。チェックを外すと両方を停止し、Startを再度押せます。
- **録音一覧・再生**：保存済みの音声・テキストを開いて聞き直します。この操作で新しい録音は始まりません。「別の音声ファイル…」から以前の録音も開けます。

録音フォルダーには音声、`.locaptio.json`、`.txt` をまとめます。録音中の入力変更では履歴を保持し、同じフォルダーに別の音声ファイルを作ります。新規録音や保存済み録音を開いた後のStartは、別の作業として新しい本文へ切り替わります。録音なしの本文は必要に応じてテキスト保存してください。

新規設定の初期値は、Windowsライブキャプション連携・日本語文字起こし、メニューバーは本文と同じ背景色、本体背景の透過率10%、字幕背景の透過率20%、英語は水色・日本語は白です。既存の認識方式・モードやカスタム設定は保持します。字幕の設定で**幅・折り返し位置**を変更できます。

Setupは更新時もインストール先の選択画面を表示します。更新ファイルを自動取得する場合でも、**インストールの許可ポップアップ**で「インストールする」を選ぶまでSetupは実行しません。「後で」を選ぶと作業を続けられます。

[**公式サイトからダウンロード**](https://locaptio.vercel.app) · [Windows版Setupを直接ダウンロード](https://github.com/Kou-256/Locaptio/releases/latest/download/Locaptio-Setup-x64.exe)

[**最新版のRelease**](https://github.com/Kou-256/Locaptio/releases/latest) から **Locaptio-Setup-x64.exe** を実行してください。管理者権限なしでインストールし、スタートメニューから起動できます。インストール先は既定で `%LOCALAPPDATA%/Programs/Locaptio` です。ZIP版も引き続き利用できます。

### 録音の検索・聞き直し（v1.0.39）

v1.0.40から再生位置に対応する**発話全体をハイライト**し、再生に合わせて追従します。マウスでスクロール・選択すると追従を止め、文字や検索結果から再生すると再開します。単語単位の正確な強調表示ではありません。

- 録音を停止すると再生バーが表示されます。**文字をクリックすると、その発話の少し前から再生**します。ドラッグ選択・Ctrl+Cは従来どおり使えます。選択範囲を右クリックして「選択した発話から再生」も可能です。
- 虫眼鏡ボタンで日本語・英語・翻訳文を検索し、**時刻付きの検索結果から再生**できます。再生・一時停止・位置スライダーに対応します。
- 録音と同じ場所に `音声ファイル名.locaptio.json` を自動保存します。「ファイル → 録音と文字起こしを開く」で再開できます。移動・共有するときは音声とJSONを一緒に扱ってください。JSONには認識した文章が含まれます。
- 発話単位の時刻です。Windows字幕の時刻は表示からの推定で、単語単位の正確な対応はありません。録音開始前の発話や過去の録音に文字・時刻を後付けする機能はありません。
- 再生音の再録音を避けるため、**聞き直しは録音停止後**に使えます。

### ローカルLLMの自動準備

AI補正／文脈LLM翻訳を有効にすると、未準備のPython環境・依存物・既定のQwen3モデルを自動取得します。PowerShellの手動実行は不要です。初回のみネット接続と数GBの空き容量が必要です。進捗は準備工程で表示し、Stop・アプリ終了で中断できます。準備済みモデルは再利用し、推論時に音声・文章を外部送信しません。カスタムモデルのパスを指定した場合は、そのファイルを用意するか設定を既定に戻してください。

### Windows字幕でマイクを使う（v1.0.40）

音声認識エンジンをWindowsライブキャプション連携、入力を**マイク（既定の入力）**にしてStartします。Windows字幕の **設定 → 基本設定 → マイク音声を含める** をONにしてください。Windowsが起動するたびに、この設定は既定でOFFになります。必要なアクセス許可はWindows側で操作してください。Windowsの既定の入力を使用し、PC音声と同時に話すとPC音声が優先されます。[Microsoftの説明](https://support.microsoft.com/en-us/accessibility/windows/use-live-captions-to-better-understand-audio)。指定した機器・アプリ・混合入力はWhisperを使用します。

Setupの追加タスクでは、スタートメニューへの追加（既定ON）とデスクトップへの追加を選べます。スタートメニューの「すべてのアプリ」へショートカットを作成するもので、ピン留めの強制変更はしません。

| 項目 | 必要条件 |
| --- | --- |
| OS／CPU | Windows 11 24H2以降、x64。ARM64版は未配布 |
| アプリの実行 | 配布ZIPに.NET／Windows App SDKを同梱 |
| Windows字幕連携のみ | Windowsライブキャプションと対象言語パック |
| Whisper・翻訳・LLM | [uv](https://docs.astral.sh/uv/getting-started/installation/)、初回セットアップ用のネット接続 |
| 空き容量 | ローカルモデル用に10GB以上を目安に確保。追加LLM・GPU/NPU環境はさらに必要 |
| ソースのビルド | [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)。アプリは.NET 8ターゲット。テストには.NET 8 Runtimeも必要 |

配布ZIPは未署名の個人ビルドです。Windowsが警告を表示する場合があります。Releaseの `SHA256SUMS.txt` でチェックサムを確認できます。セットアップはWindowsの保護機能を変更しません。

## 最短で試す：Windowsの日本語字幕を取り込む

PythonやWhisperモデルを準備せずに試せます。

1. `Locaptio.exe` を起動。
2. **設定(S) → 設定を開く… → 音声認識エンジン**で **Windowsライブキャプション連携**を選択。
3. モードを **日本語の文字起こし**、入力を **PC全体の音声**にする。
4. **Start**を押し、開いたWindowsライブキャプションの初回設定を済ませ、認識言語を日本語にする。
5. PCで日本語音声を再生する。

Windows側の字幕は開いたまま使います。連携はWindowsが公開する字幕の文字情報を読む方式で、Microsoftの認識モデルを組み込む方式ではありません。Windows更新や言語設定によって利用できない場合があります。

Windows字幕が閉じられるなどして接続が切れると、Locaptioに警告が表示され、最小化中の本体が戻ります。現在の文章と録音は保持されます。Windows字幕を起動し直すと自動再接続します。無音では警告しません。

**自動復旧は既定でON**です。PCの出力音量が確認できるのに約20秒以上字幕の更新がないと、Windows字幕と連携用プロセスを再起動し、ウィンドウが表示されたか確認します。録音・現在の文章・翻訳モデルは保持します。再試行は60秒以上空け、10分間で3回まで。失敗時は警告を残します。設定の「PC音声があるのにWindows字幕が20秒以上止まったら自動復旧」でOFFにできます。音声内容ではなく音量を判定するため、音楽・効果音や認識言語の不一致でも作動する場合があります。対象はWindows連携中のPCの既定出力音声です。

英日翻訳には次のローカル翻訳モデルの準備も必要です。Windows側の認識言語は英語にしてください。

## Whisper・英日翻訳を準備する

uvをインストールします。例：

```powershell
winget install --id=astral-sh.uv -e
```

PowerShellを開き直し、**展開したLocaptioフォルダー**へ移動して実行します。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1 -SkipBuild
```

Python 3.12環境、Whisperのbase/small、FuguMT翻訳モデルを準備します。ダウンロード・変換には時間がかかります。完了後、設定の **モデル・推論環境** にこのLocaptioフォルダーを指定してください。

- **アプリ単独の認識**：認識エンジンをWhisperにしてStart。
- **Windows認識＋英日翻訳**：Windows連携、Windowsの認識言語を英語、本アプリを英語→日本語にしてStart。
- LLM未導入の場合は **ローカルLLMで文脈を踏まえて翻訳** をOFFにするとFuguMTだけで利用できます。

## 基本操作

| 操作 | 動作 |
| --- | --- |
| Start | 新しい文字起こしセッションを開始。必要な前の文章は先に保存 |
| Stop | **文字起こしと録音を両方停止**し、録音を確定 |
| Clear | 表示・保存用テキスト履歴を消去。録音は継続 |
| 字幕 | 字幕だけのウィンドウを開き、本体を最小化。本体にも文章を保持 |
| テキスト保存 | 現在のセッション全体をUTF-8のTXTへ保存 |
| 録音チェック | ファイル名・保存先を指定して確定すると録音と文字起こしを開始。キャンセルでは開始せず、外すと録音と文字起こしを停止 |
| 履歴をスクロール | 自動スクロールを停止して読んでいる位置を保持。「最新へ」またはEndキーで追従を再開 |
| 入力・モード変更 | 字幕履歴を消去。入力変更時の録音は新ファイルへ分割 |

字幕は認識の更新が始まると表示し、無更新の時間が続くと自動で隠れます。字幕の背景をドラッグして移動でき、Escapeで閉じられます。翻訳やAI補正は同じ行へ反映します。

### マイク＋PC音声の同時入力

**PC内音声＋マイク（既定の機器・同時入力）**を選び、録音にチェックします。既定の再生機器とマイクを各50%で混ぜ、片方が無音でも継続します。

この入力では、Windows連携を選んでいても**自動でWhisperを使用**します。Whisperモデルが必要です。話者の分離・エコー除去は行いません。スピーカー音をマイクでも拾う場合はヘッドホンが役立ちます。

## 速度・精度・モデルの選び方

| 目的 | 設定・モデル |
| --- | --- |
| Windowsと同じ認識結果 | Windows連携。入力・認識言語・認識デバイスはWindows側に従う |
| 軽いWhisper認識 | base。tinyはさらに軽いものの、日本語の誤りが増える場合あり |
| 速度と精度のバランス | small |
| GPUで精度優先 | large-v3-turbo。別途ダウンロードが必要 |
| 先に表示して後で改善 | 高速文字起こし・リアルタイム速報＋独立した高精度更新 |
| 英日翻訳 | FuguMTの速報＋任意のQwen3による文脈・用語メモを使った翻訳 |
| 認識原文の後補正 | 文脈AI補正をON。LLMは別途導入。初期値はOFF |

本体画面の「AI補正」チェックボックスからもON/OFFできます。設定画面と同期し、選択状態は次回起動時にも引き継ぎます。

Windowsライブキャプション連携でも、設定の「文字起こしをAIで補正」でON/OFFできます。連携中の切り替えは即時反映されます（Whisperは次回Startから）。日本語・英語の原文をすぐ表示し、確定した発話を直前の最大8発話とともにローカルLLMで確認して、同じ行へ補正を反映します。OFFにすると未反映の補正結果を破棄し、反映済みの文章は保持します。Windows側の字幕表示は変更しません。LLM環境・モデルが未準備の場合は原文表示を続け、準備方法をステータスに表示します。

補正・翻訳は誤りを含みます。速度はモデル・PC負荷・発話長・初回読み込みに依存し、Windowsと同じモデルや速度を保証しません。

### オプションのセットアップ

設定画面は「本体の表示」「字幕の見た目」「音声認識・Windows連携」「AI文字補正」「話者識別・色分け」「翻訳・ローカルLLM」「保存先・録音」「診断」の8カテゴリから、必要な項目を展開します。モデル準備中は本体に進捗バー・完了工程％・残り工程％・現在の工程・経過時間を表示します。割合は完了した準備工程の割合です。NPU初回コンパイル内部の正確な割合や残り時間は取得できないため、工程と経過時間を表示します。

Windows字幕を手動で正しい言語へ変更して準備が完了した場合、または字幕の更新が再開した場合は、自動切り替え失敗の警告を解除します。希望言語で準備済みのWindows字幕には不要な言語選択操作を行いません。

Windows字幕の言語は、Start時と実行中のモード変更時に本体と同期します（既定ON）。英日翻訳は英語（米国）、日本語文字起こしは日本語（日本）を選びます。設定の「本体のモードにWindows字幕の言語を自動で合わせる」でOFFにできます。Windows側の言語画面が一時表示されます。言語の初回ダウンロードはWindows側で完了してください。Windows UIの変更などで自動操作できない場合は専用の警告を表示します。この連携ではWindows字幕の画面を開いておく必要があります。Windowsを起動せずに認識する場合はWhisperとCPU/GPU/AMD NPUの経路を使用します。

**話者ごとの色分け**：`scripts/setup-speakers.ps1`を実行後、設定の「音声から話者を識別し、話者ごとに色分け」をONにしてStartします。初期値はOFFです。話者1〜8の文字色と一致しきい値も設定できます。字幕は先に表示し、音声解析後に本体・独立字幕を色分けします。保存テキストには`[話者1]`などを付けます。番号はセッションごとにリセットされ、実名の特定はしません。話者色はAI補正色より優先します。

CAMPPlus（声の特徴）とSilero VAD（発話検出）をCPUで実行します。音声は端末内のメモリで処理し、話者識別のための録音保存・外部送信は行いません。Whisperでは認識と同じ入力を使います。Windows連携では本アプリで選択したPC音声とWindows字幕を取得時刻から近似対応するため、Windows側も同じ音声入力にしてください。遅延・字幕内の話者交代・短い相づち・同時発話・雑音などで誤判定する場合があります。語単位の厳密な話者分離ではなく、字幕行の主な話者を推定する機能です。判別できない場合は通常色を使います。日本語の話者識別精度は未評価です。

リポジトリまたは展開先のルートから、必要なものだけ実行します。

```powershell
# NVIDIA用ローカルCUDA DLL。NVIDIAドライバーは別途必要
powershell -ExecutionPolicy Bypass -File scripts/setup-cuda.ps1
# GPU向け高精度Whisper
powershell -ExecutionPolicy Bypass -File scripts/setup-speech.ps1 -Model large-v3-turbo
# DirectMLのGPU翻訳
powershell -ExecutionPolicy Bypass -File scripts/setup-directml.ps1
# Qwen3-4B Q4_K_M + llama.cpp（Vulkan）
powershell -ExecutionPolicy Bypass -File scripts/setup-llm.ps1
# 話者識別（ローカルCPU、モデル約29MB）
powershell -ExecutionPolicy Bypass -File scripts/setup-speakers.ps1
# LLMをCPUのみで使う場合
powershell -ExecutionPolicy Bypass -File scripts/setup-llm.ps1 -Backend cpu
# 実験的AMD Ryzen AI / XDNA 2 NPU用Whisper-small
powershell -ExecutionPolicy Bypass -File scripts/setup-amd-speech.ps1
```

AMD NPU経路はRyzen AI 9 HX 370で実機検証した実験的機能です。Windows ML・対応ドライバーが必要で、初回コンパイルは長時間かかる場合があります。NPUで行うのは専用Whisper-smallの認識で、翻訳・LLMはGPU/CPUです。すべてのPCでの動作は未確認です。[モデルとbackendの詳細](docs/model-selection.md)も参照してください。

## 保存とプライバシー

- 初回セットアップではパッケージ・モデル等をダウンロードします。**通常のローカル推論にクラウドAPIやAPIキーは使いません。**
- 録音・テキスト保存は明示的に操作したときだけ実行。文字起こしの自動保存はありません。
- 保存先を別々に設定できます。同期フォルダーでは、そのサービスがファイルを同期する可能性があります。
- 設定は `%LOCALAPPDATA%/Locaptio/settings.json`。旧版設定を初回のみ互換読み込みします。
- WAVは16kHz／16bit／mono、約115MB/時。MP3/M4Aは停止後に変換し、失敗時は元の `.recording.wav` を残します。
- 本体の履歴に行数制限はありません。文字データのメモリは利用時間に応じて増えます。音声・描画のバッファは制限しています。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| モデルなし・Start不可 | setupの完了、モデル・推論環境のフォルダー、認識エンジン |
| Windows字幕が出ない | Windows字幕を開いたままにし、認識言語をモードと合わせる |
| マイク・指定アプリで認識できない | Whisperを選ぶ。Windowsのマイク利用許可・入力機器を確認 |
| CUDAが使えない | ドライバー・setup-cuda.ps1・画面のbackendを確認。CPUも利用可能 |
| 表示が遅れる | base等の軽い速報モデル、GPU設定、他の高負荷処理を確認 |
| MP3/M4Aの停止が遅い | 変換の完了待ち。すぐ確定したい長時間録音にはWAVを選ぶ |
| 移動後に起動できない | DLL・Assets・bridgeを含むフォルダー全体を移動する |

問題は [Issues](https://github.com/Kou-256/Locaptio/issues) へ。OS・入力モード・エンジン・モデル・backend・再現手順を添えてください。個人情報を含む音声や全文ログの公開は不要です。

## 開発・ビルド

```powershell
git clone https://github.com/Kou-256/Locaptio.git
cd Locaptio
# アプリのビルド。モデル準備は別途
dotnet build src/WinUI/Locaptio.WinUI.csproj -c Release -p:Platform=x64
# ビルドとモデルをまとめて準備する場合
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1
# ソースから起動
powershell -ExecutionPolicy Bypass -File scripts/run.ps1
# 配布ZIPの生成
powershell -ExecutionPolicy Bypass -File scripts/build-portable.ps1
```

ソリューションは `Locaptio.sln`。WinUI 3が現行UI、`src/App` のWPF版は互換・検証用です。`scripts/build-msix.ps1` でMSIXを生成できますが、インストールには適切な署名が別途必要です。公開ReleaseはSetup版を基本とし、ZIP版も提供します。

録音チェックでファイル名・保存先の指定画面を開き、「保存」を確定すると録音と文字起こしを開始します。設定した録音フォルダーを最初に開き、未設定の場合は「ミュージック/Locaptio」を使用します。右下の小さな「状態」をクリックすると、本文の位置を動かさずコンパクトな状態・診断を表示します。もう一度クリックまたはEscで閉じます。ホバーでは開きません。文字起こし中も本文をドラッグして選択し、Ctrl+Cまたは右クリックのコピーを使えます。選択中の行の表示更新は選択解除まで保留し、認識・録音は継続します。「最新へ」で自動スクロールを再開します。

本文は行の途中から別の行の途中までドラッグ選択し、Ctrl+Cまたは右クリックの「選択範囲をコピー」でまとめてコピーできます。英日翻訳ではドラッグを開始した言語の列を選択します。端までドラッグすると選択方向にスクロールします。Escまたは本文の別の場所をクリックすると選択を解除します。


## 字幕表示とスクロール

設定の「字幕の見た目」で最大表示行数（既定4行）と「文章の塊で字幕を表示」を変更できます。長い字幕は指定行数に収まる最新部分を表示し、本体と保存テキストは全文を保持します。最新の発話が見える間は自動追従し、画面外まで過去へ戻った場合だけ「最新へ」を表示します。選択範囲は左ドラッグ中だけ変わり、離した後も青色と範囲を保持します。Ctrl+Cまたは右クリックでコピーし、別の箇所をクリックするかEscで解除できます。

「音声認識・Windows連携」の自動復旧は、PC音声があるのに字幕が更新されない場合に働きます。ON/OFFと待ち時間（既定180秒）を変更できます。無音だけでは再起動しません。Live Captions自体が重くなる場合は、保存・Stop後にWindows字幕を閉じ、音声認識エンジンをWhisperへ変更するとWindows字幕に依存せず認識できます。


## 保存情報と更新

Stopは録音・認識を停止し、Windowsライブキャプションと独立字幕も閉じます。本体を×で閉じた場合もWindows字幕を閉じます。本体の文章は保存・コピー用に残します。設定の「保存先・録音」で、保存日時・セッション時間（準備／無音を含み停止後は加算しない）・本文行数／発話数をそれぞれON/OFFできます。本文行数は折り返し・空行を数えません。初期ファイル名は`20261111_.txt`のような年月日です。テンプレートの`{yyyy}{MM}{dd}_`に任意の文字や`{HH}{mm}{ss}`を追加できます。保存画面でも編集可能です。

「アプリの更新」で起動時の更新確認と自動ダウンロードを切り替えます（両方既定ON）。ヘルプから手動確認も可能です。公式GitHubへの通信は公開版の情報と更新ファイル取得のみで、認識音声や文章は送信しません。更新は`%LOCALAPPDATA%/Locaptio/updates/<version>/`へ保存し、SHA-256照合後にSetupを実行できます。旧版ZIPのみのReleaseでは展開して起動してください。


設定ウィンドウは左側のSVGアイコン付きカテゴリをクリックし、右側で設定します。カテゴリ切替で値は保持され、設定は自動保存されます。
